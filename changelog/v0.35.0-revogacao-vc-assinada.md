# v0.35.0 — revogação de VC assinada

## Objetivo

Fazer da revogação de uma VC de permissão uma operação autorizada pelo emissor
da credencial, verificável no Fabric, em vez de uma alteração centralizada.

## Decisões executadas

- A wallet assina `CustodyChainCredentialRevocation` com a chave do emissor.
- Gateway e chaincode validam DID v2 ativo, `assertionMethod`, assinatura,
  janela temporal e vínculo entre emissor e credencial.
- A operação é idempotente e a implementação legada foi desabilitada.
- A aplicação só altera `CREDENCIAL.Situacao` para `REVOGADA` após o ledger
  confirmar a transação; há telas para listar e revogar credenciais emitidas.
