# v0.63.0 — Baseline e shell responsivo do frontend

## Objetivo

Estabelecer uma baseline verificável para a padronização visual e corrigir somente o shell global para reflow e zoom, sem migrar Views de domínio.

## Contratos preservados

- Shell: `_Layout.cshtml`, `_SidebarNav.cshtml`, `#sidebar-toggle`, `#sidebar-principal`, `.sidebar-scrim`, `#conteudo-principal` e skip link.
- Operações: antiforgery, `id`, `name` e hooks `data-operacao-*`; `operacao-wallet.js` continua carregado pelo layout.
- Navegação por perfil: rotas comuns `/`, `/identidade/chave`, `/relatorios/processo`, `/auditoria`; COLETOR `/vestigios/cadastrar` e `/movimentacoes/criar`; CUSTODIA `/recebimento`, `/arquivo`, `/pericias/designar`, `/destinacao-final/solicitar`; PERITO `/processamento-pericial`; ADMIN `/pericias/solicitacoes`, `/destinacao-final`, `/gestao-perfis`.

## Implementação

- Removido o bloqueio global de rolagem; o documento passa a ter `min-block-size: 100dvh`.
- O grid usa `minmax(0, 1fr)`, áreas e conteúdos usam `min-inline-size: 0`, e ações podem quebrar sem cortar identificadores, hashes ou DIDs.
- Navbar e sidebar usam dimensões fluidas; a sidebar preserva scrim, `inert`, Escape e foco no breakpoint global de `56.25rem`.
- Os breakpoints globais de componentes foram normalizados para `40rem`; temas e `prefers-reduced-motion` foram preservados.

## CSS legado inventariado para fases futuras

20 Views ainda têm CSS local: Arquivo (`Entrada`, `Index`), Auditoria (`LinhaDoTempo`, `Verificador`), Autenticação (`Entrar`, `RecuperarIdentidade`, `RotacionarChave`), DestinaçãoFinal (`Index`, `Solicitar`), Gestão de Perfis (`AtivarDidV2`, `InscricaoCriada`, `RecuperarChave`, `RevogarDidV2`), Home (`AcessoNegado`, `Index`), Movimentações (`Criar`), Perícias (`Aprovar`), Recebimento (`Index`), Relatórios (`Processo`) e Vestígios (`Cadastrar`).

Os padrões locais `grade-2col`/`grade-operacional`, `formulario-acoes`/`acoes-formulario`, `tabela-arquivo`/`tabela-operacional` e `item-recebimento`/`item-operacional` permanecem até a fase de unificação de componentes.

## Matriz de validação posterior

Validar uma rota por perfil, os temas claro/escuro, teclado, foco, skip link, sidebar, Escape e scrim nas larguras 320, 375, 768, 1024 e 1440 CSS px e nos zooms 100%, 125%, 150%, 200% e 400%. Não deve haver rolagem horizontal na estrutura global; tabelas forenses extensas podem rolar somente em seu wrapper até a migração responsiva.
